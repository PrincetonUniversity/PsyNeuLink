# Compare the PsyNeuLink Version with the Version of the paper

Study 2 from
`https://direct.mit.edu/opmi/article/doi/10.1162/opmi_a_00143/121081/Toward-the-Emergence-of-Intelligent-Control`

This implements two PsyNeuLink and two Torch versions of the EGO model from the paper:

## Original Replication

Here, we implement the PsyNeuLink version of the EGO model as described in the paper with minimal changes.

Torch version here: `torch_model_original.py` (replication of original code with minimal changes documented in
`changeSets/original.md`)

PysNeuLink version here: `pnl_model_original.py`

## Revision

Here, we implement a revised version of the EGO model with fixes.

Torch version here: `torch_model_revised.py` (with changes documented in `changeSets/revised.md`)

PsyNeuLink version here: `pnl_model_revised.py`
